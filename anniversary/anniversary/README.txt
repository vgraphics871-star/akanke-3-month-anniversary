THREE MONTHS OF US - how to run and publish

RUN LOCALLY: unzip, then double-click index.html (needs internet once for Google Fonts; falls back to Georgia otherwise).

PUBLISH FREE (pick one):
1. Netlify Drop: go to app.netlify.com/drop and drag the whole "anniversary" folder in. You get a link to send her.
2. GitHub Pages: upload the folder to a new repo, Settings > Pages > deploy from main branch.
3. Vercel: vercel.com > Add New > Project > upload the folder.

Keep index.html, story.html, moments.html, letter.html, style.css, app.js and the images folder together.
Photos are your originals, untouched. Swap them by replacing images/photo1-4.jpg.
